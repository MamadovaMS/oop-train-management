# Train Management System

Desktop-приложение для управления железнодорожными составами и моделирования их движения.

## Описание
Приложение разработано для демонстрации принципов объектно-ориентированного программирования (ООП). Позволяет создавать составы, управлять вагонами и отслеживать состояние поездов.

## Функционал
* Создание и редактирование объектов (поезда, вагоны).
* Валидация вводимых данных.
* Интуитивно понятный графический интерфейс.

## Стек технологий
* **Язык:** C#
* **Платформа:** .NET Framework / .NET Core
* **UI:** Windows Forms
* **Архитектура:** Объектно-ориентированное программирование (инкапсуляция, наследование, полиморфизм)

## Инструкция по запуску
1. Откройте файл решения `ProjectBuildozer.sln` в Visual Studio.
2. Выполните сборку проекта (Build -> Build Solution).
3. Запустите приложение (F5).
