# Train Management System

**Desktop-приложение для управления железнодорожными составами и моделирования их движения.**

Проект демонстрирует практическое применение принципов объектно-ориентированного программирования (ООП) для построения гибкой и расширяемой архитектуры.

---

## 🛠 Стек технологий
*   **Язык:** C#
*   **Платформа:** .NET 8.0 (Windows Forms)
*   **Среда разработки:** Visual Studio 2022
*   **Архитектура:** ООП (инкапсуляция, наследование, полиморфизм)

---

## ✨ Ключевой функционал
*   **Управление составами:** Создание и редактирование поездов.
*   **Управление вагонами:** Добавление, удаление и сортировка вагонов в составе.
*   **Валидация данных:** Проверка корректности ввода (например, вместимости или веса).
*   **Интуитивный интерфейс:** Удобное графическое представление состояния поездов.

---

## 🏗 Структура проекта
*   `Program.cs` — точка входа в приложение, инициализация конфигурации.
*   `Form1.cs` — основная логика работы с данными и событиями интерфейса.
*   `Form1.Designer.cs` — автоматически сгенерированный код для элементов управления 
*   `ProjectBuildozer.sln` — файл решения для Visual Studio.
